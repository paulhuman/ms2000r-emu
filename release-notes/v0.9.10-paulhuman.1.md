# Русский

Форк эмулятора Korg MS2000R на основе upstream-версии v0.9.10.

> **Внимание:** сборка предназначена только для Windows (x64). Версия для macOS (AU) не входит в этот релиз.

**Upstream:** [Tuth/ms2000r-emu v0.9.10](https://github.com/Tuth/ms2000r-emu).

## Изменения с версии v0.9.9-paulhuman.1

### Для пользователей

- **Восстановление проекта в DAW переведено на механизм upstream.** При открытии проекта плагин возвращает активную программу с текущими значениями ручек, настройки GLOBAL, режим AudioInThru и страницу LCD. Поведение осталось прежним, а новая реализация дополнительно дожидается полной загрузки машины и работает при выключенном фильтре `SystemEx` в GLOBAL.
- **Плагин немного меньше нагружает процессор.** Завершение A/D-преобразования больше не опрашивает остальную периферию на каждом втором тике. Звук не изменился.
- **Сохранены изменения форка, которых нет в upstream:** отчёт задержки host (`Report latency to host`, около 21 мс) и сохранение пропорций окна редактора при изменении размера (700×380 … 3840×2160).
- **Известное поведение.** В момент восстановления программы при открытии проекта возможен единичный щелчок. Состояние при этом восстанавливается корректно, а звук после него соответствует сохранённому проекту. Поведение относится к реализации upstream v0.9.10 и воспроизводится на чистой сборке upstream.

### Для разработчиков

- Восстановление состояния заменено апстримной реализацией в `source/plugin/PluginProcessor.cpp`: `restoreProjectEditBuffer()` ждёт загрузки машины, повторяет запрос до 15 раз, на время восстановления принудительно включает фильтр `SystemEx` (`kGlobalSysExByte = 16`, TABLE 6) и возвращает прежнее значение в `releaseForcedSysEx()`. Прежняя форковая реализация PR #8 удалена как перекрытая.
- A/D tick: в `source/core/h8s2350_emulator.*` завершение A/D-преобразования больше не тикает остальную периферию через раз. Медианное время блока ниже примерно на 1%, звук бит-в-бит.
- Сохранены `applyLatency()` (`kLatencySeconds = 0.021`) и фиксированное соотношение сторон окна (`m_constrainer.setFixedAspectRatio()` в `resized()`), которых в upstream нет.
- Проверка `MS2000R_HostTest.exe state` на чистой сборке upstream v0.9.10 даёт тот же редкий исход (`sharp steps 2`, `unexpected away from MIDI 2`, 3 прогона из 8), что и на форке. Критерий чувствителен к таймингу восстановления, а не к сохранности состояния: `state round trip: SAME` во всех прогонах.

## Соглашения форка

- Для обозначения собственных сборок используется суффикс версии `-paulhuman.<n>` (например, `v0.9.10-paulhuman.1`).
- VST3 bundle поставляется в виде каталога `MS2000R.vst3/`.
- Сборка и упаковка выполняются автоматически с помощью GitHub Actions.

## Установка

1. Распакуйте архив `MS2000R-v0.9.10-paulhuman.1-win64.zip`.
2. Скопируйте каталог `MS2000R.vst3` в каталог VST3 вашего host (например, `C:\Program Files\Common Files\VST3`).
3. Убедитесь, что доступны необходимые ROM-файлы и прошивки (см. README исходного проекта).

# English

Fork of the Korg MS2000R emulator based on upstream version v0.9.10.

> **Note:** this build is intended for Windows (x64) only. A macOS (AU) version is not part of this release.

**Upstream:** [Tuth/ms2000r-emu v0.9.10](https://github.com/Tuth/ms2000r-emu).

## Changes since v0.9.9-paulhuman.1

### For users

- **Project recall in a DAW now uses the upstream mechanism.** When a project is opened, the plugin brings back the active program with its current knob values, the GLOBAL settings, the AudioInThru option and the LCD page. The behaviour is unchanged, and the new implementation also waits for the machine to finish booting and works with the `SystemEx` filter turned off in GLOBAL.
- **The plugin uses a little less CPU.** The end of an A/D conversion no longer polls the rest of the peripherals on every other tick. The audio is unchanged.
- **Fork changes that upstream does not have are kept:** host latency reporting (`Report latency to host`, about 21 ms) and the editor keeping the panel's proportions when resized (700×380 … 3840×2160).
- **Known behaviour.** A single click is possible while the program is restored during project load. The state is still restored correctly, and the sound afterwards matches the saved project. The behaviour belongs to upstream v0.9.10 and reproduces on a clean upstream build.

### For developers

- State recall is replaced by the upstream implementation in `source/plugin/PluginProcessor.cpp`: `restoreProjectEditBuffer()` waits for the machine to boot, retries up to 15 times, forces the `SystemEx` filter on while restoring (`kGlobalSysExByte = 16`, TABLE 6) and puts the previous value back in `releaseForcedSysEx()`. The fork's own PR #8 implementation is removed as superseded.
- A/D tick: in `source/core/h8s2350_emulator.*` the end of an A/D conversion no longer ticks the rest of the peripherals every other time. The median block time is about 1% lower and the audio is bit-identical.
- `applyLatency()` (`kLatencySeconds = 0.021`) and the fixed editor aspect ratio (`m_constrainer.setFixedAspectRatio()` in `resized()`) are kept; upstream does not have them.
- `MS2000R_HostTest.exe state` on a clean upstream v0.9.10 build shows the same rare outcome (`sharp steps 2`, `unexpected away from MIDI 2`, 3 runs out of 8) as on the fork. The criterion is sensitive to recall timing, not to state integrity: `state round trip: SAME` in every run.

## Fork conventions

- Own builds are marked with a `-paulhuman.<n>` version suffix (e.g. `v0.9.10-paulhuman.1`).

- Builds and packaging are automated via GitHub Actions.

## Installation

1. Unzip `MS2000R-v0.9.10-paulhuman.1-win64.zip`.
2. Copy the `MS2000R.vst3` directory into your host's VST3 directory (e.g. `C:\Program Files\Common Files\VST3`).
3. Make sure the required ROM files and firmware are available (see the upstream project's README).
