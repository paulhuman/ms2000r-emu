# Русский

Форк эмулятора Korg MS2000R на основе upstream-версии v0.9.8.

> **Внимание:** сборка предназначена только для Windows (x64). Версия для macOS (AU) не входит в этот релиз.

**Upstream:** [Tuth/ms2000r-emu v0.9.8](https://github.com/Tuth/ms2000r-emu).

## Изменения с версии v0.9.8-paulhuman.1

### Для пользователей

- **Ручки теперь показывают значения текущего пресета.** Раньше они оставались там, где вы их оставили. Теперь при открытии проекта или загрузке пресета ручки сразу показывают его значения. Если вам удобнее прежнее поведение, отключите настройку `Knobs show the program`.

### Для разработчиков

- Значение флага `knobFollow` по умолчанию изменено с `false` на `true` (`PluginProcessor.h`). Это же значение теперь используется в качестве fallback при восстановлении состояния из проекта (`PluginProcessor.cpp`). Глобальная настройка и механизм сохранения настройки в проекте не изменялись.

## Соглашения форка

- Для обозначения собственных сборок используется суффикс версии `-paulhuman.<n>` (например, `v0.9.8-paulhuman.2`).
- VST3 bundle поставляется в виде каталога `MS2000R.vst3/`.
- Сборка и упаковка выполняются автоматически с помощью GitHub Actions.

## Установка

1. Распакуйте архив `MS2000R-v0.9.8-paulhuman.2-win64.zip`.
2. Скопируйте каталог `MS2000R.vst3` в каталог VST3 вашего хоста (например, `C:\Program Files\Common Files\VST3`).
3. Убедитесь, что доступны необходимые ROM-файлы и прошивки (см. README исходного проекта).

# English

Fork of the Korg MS2000R emulator based on upstream version v0.9.8.

> **Note:** this build is intended for Windows (x64) only. A macOS (AU) version is not part of this release.

**Upstream:** [Tuth/ms2000r-emu v0.9.8](https://github.com/Tuth/ms2000r-emu).

## Changes since v0.9.8-paulhuman.1

### For users

- **Knobs now show the values of the current program.** Previously they remained where you left them. Now, when you open a project or load a program, the knobs immediately show its values. Prefer the old behavior? Turn off `Knobs show the program` in settings.

### For developers

- The `knobFollow` flag's default changed from `false` to `true` (`PluginProcessor.h`). The same value is now used as the fallback when restoring state from a project (`PluginProcessor.cpp`). The global setting and the per-project persistence mechanism are unchanged.

## Fork conventions

- Own builds are marked with a `-paulhuman.<n>` version suffix (e.g. `v0.9.8-paulhuman.2`).
- The VST3 bundle ships as a `MS2000R.vst3/` directory.
- Builds and packaging are automated via GitHub Actions.

## Installation

1. Unzip `MS2000R-v0.9.8-paulhuman.2-win64.zip`.
2. Copy the `MS2000R.vst3` directory into your host's VST3 directory (e.g. `C:\Program Files\Common Files\VST3`).
3. Make sure the required ROM files and firmware are available (see the upstream project's README).
