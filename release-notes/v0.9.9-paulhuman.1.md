# Русский

Форк эмулятора Korg MS2000R на основе upstream-версии v0.9.9.

> **Внимание:** сборка предназначена только для Windows (x64). Версия для macOS (AU) не входит в этот релиз.

**Upstream:** [Tuth/ms2000r-emu v0.9.9](https://github.com/Tuth/ms2000r-emu).

## Изменения с версии v0.9.8-paulhuman.2

### Для пользователей

- **Повышена производительность** — сборка с профильной оптимизацией (PGO) делает standalone-приложение примерно на 14% быстрее, а плагин расходует примерно на 7% меньше CPU. Звучание не изменилось.
- **LCD-дисплей отображается как настоящая матрица точек** — символы рисуются из ровных круглых точек при любом размере окна, без растягивания и искажений.

### Для разработчиков

- PGO-сборка (MSVC): реализована профильная оптимизация для standalone и плагина через флаг `MS2K_PGO` (`GEN`/`USE`, см. `CMakeLists.txt`). Профиль обучается на контрольном прогоне; оптимизированная сборка быстрее и легче, звук бит-в-бит тот же.
- LCD-DOTS-1: LCD перерисован как dot-matrix на уровне устройства (`dotCover`/`drawLcd` в `PluginEditor.cpp`) — каждая точка вычисляется для точного размера окна, масштабирование не дублирует столбцы.

## Полный список изменений форка

Все заметки выпусков форка собраны в каталоге [release-notes](https://github.com/paulhuman/ms2000r-emu/tree/main/release-notes).

## Соглашения форка

- Для обозначения собственных сборок используется суффикс версии `-paulhuman.<n>` (например, `v0.9.9-paulhuman.1`).
- VST3 bundle поставляется в виде каталога `MS2000R.vst3/`.
- Сборка и упаковка выполняются автоматически с помощью GitHub Actions.

## Установка

1. Распакуйте архив `MS2000R-v0.9.9-paulhuman.1-win64.zip`.
2. Скопируйте каталог `MS2000R.vst3` в каталог VST3 вашего хоста (например, `C:\Program Files\Common Files\VST3`).
3. Убедитесь, что доступны необходимые ROM-файлы и прошивки (см. README исходного проекта).

# English

Fork of the Korg MS2000R emulator based on upstream version v0.9.9.

> **Note:** this build is intended for Windows (x64) only. A macOS (AU) version is not part of this release.

**Upstream:** [Tuth/ms2000r-emu v0.9.9](https://github.com/Tuth/ms2000r-emu).

## Changes since v0.9.8-paulhuman.2

### For users

- **Performance improved** — the profile-guided (PGO) build makes the standalone application about 14% faster and the plugin use about 7% less CPU. The audio is unchanged.
- **The LCD is now rendered as a real dot matrix** — characters are drawn from even, round dots at any window size, without stretching or distortion.

### For developers

- PGO build (MSVC): profile-guided optimisation for the standalone and the plugin via the `MS2K_PGO` flag (`GEN`/`USE`, see `CMakeLists.txt`). The profile is trained on a reference run; the optimised build is faster and lighter, with bit-identical audio.
- LCD-DOTS-1: the LCD is redrawn as a device-level dot matrix (`dotCover`/`drawLcd` in `PluginEditor.cpp`) — each dot is computed for the exact window size, so scaling never duplicates columns.

## Full list of fork changes

All fork release notes are collected in the [release-notes](https://github.com/paulhuman/ms2000r-emu/tree/main/release-notes) directory.

## Fork conventions

- Own builds are marked with a `-paulhuman.<n>` version suffix (e.g. `v0.9.9-paulhuman.1`).
- The VST3 bundle ships as a `MS2000R.vst3/` directory.
- Builds and packaging are automated via GitHub Actions.

## Installation

1. Unzip `MS2000R-v0.9.9-paulhuman.1-win64.zip`.
2. Copy the `MS2000R.vst3` directory into your host's VST3 directory (e.g. `C:\Program Files\Common Files\VST3`).
3. Make sure the required ROM files and firmware are available (see the upstream project's README).
